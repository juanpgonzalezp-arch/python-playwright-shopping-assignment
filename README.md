Python Playwright Shopping Assignment
Requirements
Python 3.12+
Playwright
Installation
pip install playwright
playwright install
Files
01_login.py
Logs into the application.

02_add_to_cart.py
Adds products to the shopping cart.

03_cart_validation.py
Validates cart contents and item count.

Run scripts
python 01_login.py
python 02_add_to_cart.py
python 03_cart_validation.py
